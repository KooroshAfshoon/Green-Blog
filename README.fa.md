# Green Blog

یک وبلاگ شخصی سبک و ساده، نوشته‌شده با PHP خام (PDO/MySQL) و جاوااسکریپت ساده — بدون فریم‌ورک و بدون مرحله‌ی build. رابط کاربری راست‌به‌چپ و فارسی، با فونت وب Vazir.

## امکانات

- فهرست پست‌ها با قابلیت پین کردن، فیلتر بر اساس تگ، و صفحه اختصاصی هر پست
- لایک / آنلایک پست‌ها (با AJAX، بدون رفرش صفحه)
- ثبت بازدید (هم برای هر پست، هم کلی سایت — با جلوگیری از ثبت تکراری در بازه ۳۰ دقیقه بر اساس IP)
- آپلود چند تصویر برای هر پست، با قابلیت تبدیل تصویر به **ASCII art**
- تگ‌های هشتگی (`#php #linux`) که به‌صورت خودکار از متن پست استخراج می‌شن
- پنل مدیریت ساده مبتنی بر سشن (ساخت / ویرایش / حذف پست، داشبورد آمار)
- آدرس تمیز برای پست‌ها (`/post/42`) از طریق `.htaccess`

## پیش‌نیازها

- PHP نسخه ۷.۴ به بالا (از `PDO`، `password_verify`، `mbstring` و GD برای تبدیل ASCII استفاده می‌کنه)
- MySQL یا MariaDB
- Apache با `mod_rewrite` فعال (برای قانون آدرس تمیز در `.htaccess`) — برای nginx باید قانون rewrite رو خودتون معادل‌سازی کنید

## راه‌اندازی

1. **مخزن رو کلون کنید** و روی هاست PHP آپلود کنید، یا به‌صورت لوکال اجرا کنید.

2. **یک دیتابیس بسازید** و schema رو ایمپورت کنید:
   ```bash
   mysql -u youruser -p your_database < schema.sql
   ```

3. **فایل تنظیمات محلی خودتون رو بسازید:**
   ```bash
   cp config.example.php config.php
   ```
   فایل `config.php` رو باز کنید و اطلاعات واقعی دیتابیس و اطلاعات ورود ادمین رو پر کنید.

   برای ساخت هش رمز عبور ادمین:
   ```bash
   php -r "echo password_hash('your-password-here', PASSWORD_DEFAULT), PHP_EOL;"
   ```
   خروجی رو داخل `admin_pass_hash` در `config.php` قرار بدید.

4. **پوشه‌های `uploads/` و `ascii/` باید برای وب‌سرور قابل نوشتن باشن:**
   ```bash
   chmod 755 uploads ascii
   ```

5. آدرس `index.php` رو در مرورگر باز کنید. برای دسترسی به پنل مدیریت، از `login.php` با اطلاعاتی که در `config.php` تنظیم کردید وارد بشید.

## ساختار پروژه

```
index.php            فهرست پست‌های وبلاگ (فیلتر بر اساس تگ)
post.php             نمایش تکی یک پست
admin.php            پنل مدیریت — ساخت پست، آمار
edit.php             ویرایش / حذف یک پست موجود
login.php            ورود ادمین
like.php             endpoint مربوط به لایک/آنلایک (AJAX)
track_view.php        منطق ثبت بازدید (توسط index.php و post.php استفاده می‌شه)
helpers.php          استخراج تگ، تخمین زمان مطالعه، رندر چیپ تگ‌ها
ascii_converter.php  تبدیل تصویر آپلودشده به ASCII art
db.php               بارگذاری config.php و اتصال PDO
config.example.php   نمونه تنظیمات — کپی کنید به config.php و مقادیر خودتون رو بزنید
schema.sql           ساختار دیتابیس
style.css / script.js
fonts/Vazir.ttf       فونت وب فارسی
uploads/, ascii/      محتوای تولیدشده در زمان اجرا (در git نادیده گرفته می‌شن، فقط .gitkeep نگه‌داشته شده)
```

## نکات امنیتی

- فایل `config.php` در `.gitignore` قرار داره — هیچ‌وقت اطلاعات واقعی دیتابیس یا هش رمز ادمین رو کامیت نکنید.
- رمز عبور ادمین به‌صورت هش bcrypt (`password_hash` / `password_verify`) ذخیره می‌شه، نه متن ساده.
- اگه این پروژه رو فورک می‌کنید، `login.php` رو فقط به‌عنوان نقطه شروع در نظر بگیرید — برای هر چیزی که عمومی و در دسترس اینترنت قرار می‌گیره، بهتره rate limiting و محافظت CSRF هم اضافه کنید.

## لایسنس

فعلاً لایسنسی مشخص نشده — اگه قصد دارید مشارکت بپذیرید یا شرایط استفاده رو شفاف کنید، یک لایسنس (مثلاً MIT) اضافه کنید.
